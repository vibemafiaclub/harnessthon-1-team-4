# 00-clarify

## A. 실행 인자

| 항목 | 값 | 출처 |
|---|---|---|
| 작업 Page | `3-toss-result` | 인자 · PRD 7절 "신규 화면은 **`3-toss-result` Page**에 만들어주세요" |
| 참조 Page | `3-toss` (화면 4개: 홈(자산 요약)·혜택·전체 메뉴·상세) | PRD 2절 "읽을 대상: **`3-toss` Page** — 화면 4개가 들어 있습니다" |
| 읽기 제외 | `3-toss` 는 **읽기 전용**(쓰기 금지). 그 외 배제 Page 지정 없음 | PRD 7절 "(`3-toss`는 읽기 전용입니다)" |
| 파일 위치 | `제출용` 팀 / `최종제출_4팀` 파일 | PRD 2절 |
| 프레임 접두사 | 최상위 프레임 이름 `New/` 로 시작 (`New/Home`, `New/Results`) | PRD 7절 |
| 화면 가로 폭 | 390 고정 (세로는 내용에 맞게 가변) | PRD 7절 |
| PRD 모양 | **기존앱 + 신규도메인** (기존 자산 승계 + 톤앤매너 유지 조항 존재) | PRD 2절 · 6절 |

> 이하 모든 절에서 참조 제품의 브랜드명·서비스명을 쓰지 않는다. 참조 대상은 **`A절 참조 Page`** 로만 지칭한다.
