## B. 대상 사용자

- 주식을 처음 시작하는 사람 — 무엇을 봐야 할지 모른다 (1절)
- 가입 첫날이라 관심종목이 **비어 있는** 신규 유입 사용자 (5절 · 3절 스토리4)
- **투자 스타일을 아직 고르지 않은** 사용자 (5절 · 4-2)
- 먼저 보고 싶은 지표가 서로 다른 사용자 — 등락률 / 내 수익률 / 거래량, 스타일 4종(단기·배당·성장·안정), 테마 편중 (3절 스토리2 · 4-2 · 4-3)

## C. 이탈 원인

- **C1.** 증권 앱 첫 화면에서 · 한 화면에 숫자가 수십 개라 · 무엇을 봐야 할지 몰라 첫 화면에서 이탈한다 (1절)
- **C2.** 관심종목이 비어 있는 상태에서 · 무엇을 살지 정할 단서가 없어 · 아무것도 시작되지 않고 멈춘다 — PRD가 지목한 **가장 큰 이탈 지점** (3절 스토리4 · 5절)
- **C3.** 시세 미수신 · 잔고 부족 · 장 마감 상황에서 · 화면이 비거나 주문이 실패해 다음 행동을 못 찾는다 (5절)

## D. 제품 정의

주식을 처음 시작하는 사람을 위해, 첫 화면에서 숫자를 수십 개 쏟아내는 기존 증권 앱을 대신하는, 동네 이웃과 중고거래하듯 부담 없고 익숙한 흐름으로 관심종목 담기부터 매수까지 이어주는 제품. (1절)

## E. 디자인 원칙

- **E1.** 반복 목록의 한 행에는 강조 수치 1개(현재가) + 보조 수치 1개(등락률)만 둔다 — 행당 숫자 텍스트 3개를 넘기지 않는다 (← C1 / 검사법: 목록 행 컴포넌트의 텍스트 노드 중 숫자 포함 개수를 센다, ≤3)
- **E2.** 상승/하락은 색 단독으로 구분하지 않고 부호(+/− 또는 ▲/▼)와 값을 함께 쓰며, 등락색은 수치·배지에만 쓰고 배경·큰 면적 채움에는 쓰지 않는다 (← C1 / 6-1 필수요소 "상승/하락의 시각적 구분"을 막지 않음 / 검사법: 등락 표시 요소마다 부호 문자 존재 여부 + 등락색으로 채워진 면적 요소가 있는지 찾는다)
- **E3.** 추천·발견 성격의 카드에는 "왜 이것인가"를 말하는 한 줄이 반드시 붙는다 (← C2 / 4절 지시 · 6-3 필수요소 / 검사법: `New/Discover` 계열의 추천 카드마다 이유 텍스트 노드 1개 존재)
- **E4.** 비어 있음·로딩·실패 상태를 그대로 두지 않는다 — 각 상태 화면에 다음 행동 버튼을 1개 이상 둔다 (← C2 · C3 / 검사법: 상태변형 프레임마다 버튼 역할 노드 ≥1)
- **E5.** 사용자가 고른 것(투자 스타일·테마·정렬)은 결과 화면 위에 지금 무엇이 적용 중인지 보이게 둔다 (← C2 / 4절 "선택이 추천에 실제로 반영되는 것처럼" / 검사법: Discover·Watchlist 상단에 현재 선택을 나타내는 칩/라벨 노드 존재)
